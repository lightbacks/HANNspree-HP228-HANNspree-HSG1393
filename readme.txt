Hannspree HP228PJB comes as a [[60hz]] monitor by default.

It is capable of [[70, 75 and 80hz]] operation which is technically an overclock and not guaranteed.



To see which modes your particular unit can run,

===>		launch [hannspree.exe]
===>		select "install EDID"

In Windows display settings, new refresh rate options will show up.


If you have established 80hz runs stable on your monitor, you can run

===>		launch [80hz_only.exe]
===>		select "install EDID"

This way you will avoid some games choosing 60hz for some reason
That will leave 1080p 80hz as the only option to be considered by the PC


!!!!!  THE CHANGES WILL APPLY ONCE YOU RUN [restart64.exe] !!!!!


Default colors and gamma are a bit too punchy, the darks a bit too crushed.
To make the colors / gamma more faithful, for photo editing for example,

===>		Using monitor OSD, set the white balance to 6500K
===>		Set brightness to 96-98, contrast 80, sharpness 40
===>		double click [hannspree.icc]

Optionally make sure the .icc is in effect in Color management menu (Control Panel)
Make sure the monitors OSD displeys the refresh rate as 80Hz / whatever other setting you have tried to set.


At 80Hz specifically, the overdrive setting (in the monitor's OSD) is not excessive and should be kept on. At 60hz it's over the top, so leaving it off is understandable during standard operation.


TO GO BACK TO INITIAL STATE RUN [hannspree.exe] and select "Reset EDID" option
THE CHANGES WILL APPLY ONCE YOU RUN [restart64.exe]
